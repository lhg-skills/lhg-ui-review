# 走查框架详解（references）

> 本文件是 SKILL.md Phase 3 的展开手册：五个支柱的检查细则、"AI 味"反模式清单、中文排版速查。走查时按需查阅，不必一次读完。

---

## 支柱 1：可用性与信息架构——检查细则

- **主行动唯一性**：一屏只许有一个主行动。出现两个并排、同等分量的 CTA，先判为 P1。
- **步骤计数**：从进入页面到完成主行动，数点击/输入次数。超过 3 步且无进度提示，记 P1。
- **认知负荷**：用户同时要做的判断（选哪个、填什么、信什么）超过 3 个，记 P1；给"渐进披露"方案。
- **空/加载/错误态**：三个状态缺任何一个，记 P1（错误态缺"怎么改"指引，升 P0）。
- **导航诚实**：导航项点进去的内容与标签名不符，记 P1。

## 支柱 2：视觉层级与布局——检查细则

- **阅读动线**：落地页走 Z 型（logo→主标题→CTA→次级信息），内容页走 F 型。动线断裂处即问题点。
- **字阶**：标题/正文比例拉到 1.25 以上；全站字号种类 >6 即超标（P1）。
- **网格**：4/8pt 网格对齐检查，游离元素逐个点名（P2，可批量修）。
- **留白**：段间距 < 行内间距、内容贴边，是廉价感的两大来源（P1）。

## 支柱 3：一致性审计——操作方法

1. 把页面所有间距值列出来（如 8/12/15/16/20/24），近似值（15 vs 16）直接记 P1，统一为一档。
2. 把所有灰色列出来，两坨肉眼难分的灰记 P1，合并。
3. 把所有圆角/阴影列出来，超过 3 档记 P2，建议收敛到 2 档。
4. 同一语义元素（主按钮/次按钮/卡片/输入框）截图并排对比，任一不一致记 P1。

## 支柱 4：无障碍——速查阈值

| 检查项 | 阈值 | 说明 |
|---|---|---|
| 正文对比度 | ≥ 4.5:1 | WCAG AA |
| 大字（≥24px 或 19px 加粗）对比度 | ≥ 3:1 | WCAG AA |
| 触摸目标 | ≥ 24px | AA；重要操作建议 44px |
| 焦点指示 | focus-visible 可见 | 键盘用户生命线 |
| 色盲 | 不用纯颜色传达状态 | 红/绿状态必须配文字或图标 |

B 档（截图）输入下，只能评"视觉可确立"的部分（如对比度估算、目标尺寸），其余标"未验证"。

## 支柱 5：文案与交互反馈——检查细则

- CTA 动词化："提交"→"免费试用 14 天"，"了解更多"→"查看定价方案"。
- 占位符禁令：占位符文字不许承担标签职责。
- 错误信息三要素：哪里错了 + 为什么错 + 怎么改，缺一记 P1。
- 成功态：操作成功后用户知道"接下来去哪"，缺则记 P2。

## "AI 味"反模式清单（中文语境，独立撰写）

命中一项扣 5 分（上限 -20）。每项格式：识别方法 → 为什么伤 → 替代方案。

1. **紫蓝渐变滥用**：背景/按钮无脑紫→蓝渐变。识别：渐变方向 135°、色相横跨 240°→200°。伤：2023 年之后所有 AI 生成页都长这样，用户已产生"模板脸"免疫。改：换单色 + 用明度/饱和度做层次。
2. **卡片堆砌**：所有内容都装进圆角卡片，无信息层级。识别：一屏超过 6 张同样式卡片。伤：卡片是"分组"工具，不是"排版"工具。改：用字阶+留白分组，卡片只留给真正需要边界的内容。
3. **统一圆角 + 模板阴影**：所有元素 12px 圆角 + 同一款弥散阴影。识别：截图取 3 处圆角值完全一致。伤：精致感来自"有控制的差异"，不是统一。改：按层级定 2 档圆角，阴影只给浮层。
4. **emoji 当图标**：用 emoji 代替绘制图标。识别：✨🎉🚀 出现在正式 UI 中。伤：emoji 在不同系统渲染不一致，且传递"没时间画图标"的信号。改：用线性图标库统一替换。
5. **占位图充数**：灰色块/Unsplash 风景图当"设计完成"。识别：图片与文案无语义关联。伤：用户一眼看出是模板。改：删掉，或换与内容相关的示意图/数据可视化。
6. **居中对称排版**：所有标题段落居中。识别：连续 3 屏以上无左对齐文本。伤：居中无阅读动线，信息扫描效率最低。改：标题左对齐，只在 hero 区保留居中。
7. **单一字号弱字阶**：正文 14/16 通吃，标题只大两号。识别：全页字号种类 ≤3 且标题/正文比 <1.2。伤：没有字阶就没有层级。改：拉开到 1.25+，标题用字重（700）而非单纯放大。
8. **模板胶囊按钮**：圆角胶囊 + 渐变 + 白字，无状态区分。识别：hover/disabled 与常态无视觉差。伤：用户不知道"我点了吗""还能点吗"。改：补齐 5 种状态，胶囊只给主 CTA 用。
9. **纯灰配色**：黑白灰 + 一个强调色，无色彩情绪。识别：取色 90% 落在灰轴。伤：不出错，也不出彩；品牌无记忆点。改：给强调色定"情绪用途"（信任/活力/高级），灰只做底。
10. **默认动效**：全场 fadeInUp，无节奏无主次。识别：滚动时所有元素同一曲线同一时长上浮。伤：动效是"引导视线"的工具，齐飞等于没引导。改：只给主行动和关键转场加动效，时长 120–250ms，ease-out。
11. **Inter 直排中文**：西文字体硬套中文，字重/字距失衡。识别：中文笔画发虚、标点挤压。改：中文走 Noto Sans SC / PingFang SC / Microsoft YaHei 栈。
12. **内容顶满无留白**：信息密度恐惧症，边距 <16px。识别：截图四边无呼吸。改：内容区左右留白 ≥24px（移动端 ≥16px），段间距 ≥1.5 倍行高。

## 中文排版速查

- 字体栈：标题 `Noto Serif SC, Songti SC, serif`；正文 `Noto Sans SC, PingFang SC, Microsoft YaHei, sans-serif`。
- 标点：全角（，。：；）；中英混排英文前后半角空格；数字与单位不加空格。
- 标题 ≤12 字，超了拆主副标题；禁"关于……的几点思考"式公文标题。
- 中文行高建议 1.6–1.8，行宽 35–45 个汉字为宜。
